# Attache downloads

Built installers for [Attache](https://attache-cloud-production.up.railway.app).
This repository holds releases only -- no source.

## Latest

**Attache 0.2.0 for Windows 10/11 (64-bit) -- 445 MB**

The download includes the local model, so Attache answers questions as soon
as it finishes installing: no account, no API key, and no separate Ollama
install.
